# Imprimir Ender

Программа для Windows (Python + tkinter), которая **нарезает, располагает и печатает** на **Creality Ender-3 V3 SE** прямо по USB: 3D-стол, ручная цветная печать, редактор деталей, наблюдение по камере с ИИ, страница для телефона и **MCP-сервер**, чтобы ИИ (Claude, Cursor и др.) мог всем управлять.

**Читать на:** [Português](README.md) · [English](README.en.md) · [Español](README.es.md) · Русский

> Интерфейс на **португальском, английском, испанском и русском**.

## Статус: этап тестирования

Что уже используется на практике и работает: печать (нарезка CuraEngine, отправка по USB, СТОП), 3D-стол, страница для телефона и MCP-сервер.

**Ещё НЕ проверено по-настоящему на принтере** (код есть, но тестируется): цветная печать со сменой филамента, диагностические тесты, редактор деталей, импорт цветного 3MF, создание деталей через Zoo и наблюдение по камере с ИИ. Это проверялось только на имитации принтера. Держите принтер на виду и ожидайте доработок. Отчёты и исправления приветствуются.

## Возможности

**Печать**
- Открывает STL или G-code, нарезает через CuraEngine (пресеты: ABS полный, ABS быстрый, PLA), показывает время и стоимость.
- Отправляет G-code построчно, ожидая `ok`; при ошибке выключает сопло и стол. Кнопка СТОП всегда доступна.
- Безопасный старт: сначала стол, G28, загрузка сохранённой карты выравнивания, вентилятор по материалу.
- Пауза, продолжение, смена филамента (M600), датчик филамента, очередь печати.
- Сам находит порт принтера.

**3D-стол**
- Несколько деталей: перемещение, поворот, масштаб, копирование, автораскладка, заполнение стола.
- Собственный 3D-просмотр, показывает и **поддержки**.
- Импорт **цветного 3MF** (PrusaSlicer, Bambu/Orca — по возможности, стандартный 3MF): каждая часть становится деталью со своим цветом.
- «Печатать только один цвет»: по одному цвету, меняете филамент и повторяете.
- Поддержки: дерево или обычные, узор, плотность, зазор Z/XY, потолок.

**Ручная цветная печать**
- Смена цвета по слоям; программа ставит паузу, отводит сопло в угол, выгружает/загружает филамент и ждёт вас.

**Редактор деталей** (отдельная вкладка)
- Отверстие, срез плоскостью, фигуры (добавить/вычесть), рельефный или гравированный текст на 5 гранях, полигоны от руки, отмена, возврат к оригиналу. Исходный файл не меняется: копия сохраняется в `pecas_editadas`.

**Создание детали по тексту (Zoo)**
- Создаёт деталь по описанию через Zoo (zoo.dev). Нужен ваш собственный ключ и разрешение во вкладке.

**Тесты принтера**
- 12 тестов: связь, термисторы, концевики, датчик филамента, SD-карта, экран, вентилятор, CR Touch, нагрев сопла, нагрев стола, моторы, экструдер. Тесты с нагревом или движением просят разрешение; в конце нагреватели всегда выключаются.

**Наблюдение по камере**
- Фото принтера через заданные промежутки (IP-камера) отправляется ИИ (JEV, OpenAI или Gemini; модель выбираете вы) для поиска сбоев. Уведомления Pushover по желанию.

**Прочее**
- Выравнивание при тёплом столе, калибровка, стоимость катушки, история, таймлапс, вкладка «Руководство».
- **Веб-приложение для телефона** (PWA, 4 языка): статус, цвета, камера, стол и кнопка СТОП. Защищено токеном.
- Локальный HTTP-сервер (порты 8101–8110) с API, которое использует MCP.

## MCP (управление программой с помощью ИИ)

`mcp_ender/server.py` даёт **61 инструмент**: статус, печать (требует подтверждения), 3D-стол, цвета, редактирование деталей (ИИ может *видеть* деталь), диагностика, Zoo, расширенный режим, камера и наблюдение. Полный список — в [`mcp_ender/MANUAL_MCP.md`](mcp_ender/MANUAL_MCP.md) (на португальском).

MCP не обращается к принтеру напрямую, а вызывает API программы, поэтому защитные блокировки действуют и для ИИ. Во вкладке **IA / MCP** можно создать/скопировать токен, скопировать готовую команду для Claude Code или JSON для других клиентов и включить режим **только чтение**.

## Установка

1. Windows с Python 3.12.
2. Установите [UltiMaker Cura](https://ultimaker.com/software/ultimaker-cura/) (используется его CuraEngine; в репозиторий он **не** входит). Путь указан в `base_ender.py` (`CURA = ...`).
3. `pip install -r requirements.txt`
4. Подключите принтер по USB и запустите `Imprimir_Ender.bat` (или `pythonw imprimir_ender.py`).

Другие похожие принтеры на Marlin могут заработать после правки `perfil_impressora.json` и пресетов в `base_ender.py`.

## Безопасность и приватность

- Ключи ИИ (JEV/OpenAI/Gemini/Zoo) и сетевой токен хранятся в файлах `_PRIVADO_*` на вашем ПК и **игнорируются git**. Никогда их не публикуйте.
- Программа никогда не использует ключ, который вы не вводили.
- **ИИ печатает только по вашей команде**: `ender_imprimir` требует `confirmo=true`; тесты с нагревом или движением тоже требуют явного разрешения. Кнопка СТОП и режим **только чтение** действуют и для ИИ.
- **Общается только с вашей сетью**: MCP обращается лишь к локальному API программы (`ENDER_URL`, по умолчанию `http://127.0.0.1:8101`) с вашим токеном и ничего не отправляет третьим лицам.
- **Аннотации инструментов**: каждый инструмент MCP объявляет `readOnlyHint` (только чтение) или `destructiveHint` (может нагревать, двигать, печатать, удалять).
- Тесты: `python -m pytest tests`; ни один не использует принтер.

## Перевод на другой язык

`python traduzir_idiomas.py --codigo fr --nome "Français"` переводит все тексты через API Claude (дешёвая модель, пакетами; нужен `ANTHROPIC_API_KEY`). `--simular` показывает стоимость без вызова. Затем добавьте язык в `i18n.IDIOMAS`. Ограничения: значения выпадающих списков и некоторые динамические сообщения остаются на португальском.

## Известные ограничения

- Только равномерный масштаб; детали больше стола (220 x 220 мм) отклоняются.
- 3MF Bambu/Orca не проверялся на реальных файлах.
- Цветная печать ручная (смена филамента), не автоматическая мультиматериальная.
